透過會傾聽你演奏的課程學習鋼琴、吉他和小提琴，另有免費調音器和原聲鋼琴檢測。

## Description

Music Portal 用簡短友好、會傾聽你演奏的課程，幫助你學習鋼琴、吉他和小提琴。它以前叫 Midivory，你的賬戶和進度都會保留。

**會傾聽的課程**
彈奏你自己的樂器，Music Portal 會透過麥克風傾聽，檢查你的音符和節奏。彈小提琴時，還會顯示每個音離準確音高有多近。彈吉他時，和絃會標為正確或錯誤，並給出聽到內容的提示。麥克風收到的所有聲音都在你的電腦上分析，然後丟棄。不會錄音，也不會上傳任何音訊。

**鋼琴、吉他和小提琴**
- 鋼琴：可使用 USB MIDI 鍵盤或螢幕鍵盤。使用原聲鋼琴時，麥克風模式會評判單旋律。藍芽 MIDI 鍵盤稍後將在 Windows 上支援。
- 吉他：五線譜與六線譜，和絃圖，以及螢幕指板。
- 小提琴：指法、把位和弓法標記，以及螢幕指板。
- 上線時，吉他和小提琴課程涵蓋從入門到中級初期。更多課程將在稍後推出。

**免費調音器**
半音階調音器無需賬戶，也無需聯網。可選擇吉他預設（標準、Drop D、DADGAD、開放調絃等）、小提琴預設或鋼琴模式。可自定義參考音高（A4 為 415 至 466 Hz），並儲存自定義調絃。

**鋼琴檢測**
想知道你的原聲鋼琴是否需要調音？彈奏應用要求的音，檢視哪些音偏高或偏低、偏差多少，以及整臺鋼琴是否整體下沉。清晰的結論幫你決定是否請鋼琴調音師。它只做測量，不教調音。引導式調音輔助將稍後推出。

**每天練一點**
每日挑戰、測驗、連續記錄和經驗值幫你堅持下去。一個賬戶可在網頁、Android 和 Windows 上使用。

**免費與付費**
調音器和每種樂器的前幾節課免費。部分後續課程和額外工具屬於可選升級。如果你已在使用這個應用，你現有的一切仍歸你所有。

**隱私**
只有當你開啟課程、調音器或鋼琴檢測時，Music Portal 才會請求麥克風許可權，並會先說明原因。如果你拒絕，使用 MIDI 鍵盤或螢幕樂器的所有功能仍可正常使用。

有問題或想法？請使用應用內的“傳送反饋”。
