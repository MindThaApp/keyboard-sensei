## Description

Music Portal 用简短友好、会倾听你演奏的课程，帮助你学习钢琴、吉他和小提琴。它以前叫 Midivory，你的账户和进度都会保留。

**会倾听的课程**
弹奏你自己的乐器，Music Portal 会通过麦克风倾听，检查你的音符和节奏。弹小提琴时，还会显示每个音离准确音高有多近。弹吉他时，和弦会标为正确或错误，并给出听到内容的提示。麦克风收到的所有声音都在你的电脑上分析，然后丢弃。不会录音，也不会上传任何音频。

**钢琴、吉他和小提琴**
- 钢琴：可使用 USB MIDI 键盘或屏幕键盘。使用原声钢琴时，麦克风模式会评判单旋律。蓝牙 MIDI 键盘稍后将在 Windows 上支持。
- 吉他：五线谱与六线谱，和弦图，以及屏幕指板。
- 小提琴：指法、把位和弓法标记，以及屏幕指板。
- 上线时，吉他和小提琴课程涵盖从入门到中级初期。更多课程将在稍后推出。

**免费调音器**
半音阶调音器无需账户，也无需联网。可选择吉他预设（标准、Drop D、DADGAD、开放调弦等）、小提琴预设或钢琴模式。可自定义参考音高（A4 为 415 至 466 Hz），并保存自定义调弦。

**钢琴检测**
想知道你的原声钢琴是否需要调音？弹奏应用要求的音，查看哪些音偏高或偏低、偏差多少，以及整台钢琴是否整体下沉。清晰的结论帮你决定是否请钢琴调音师。它只做测量，不教调音。引导式调音辅助将稍后推出。

**每天练一点**
每日挑战、测验、连续记录和经验值帮你坚持下去。一个账户可在网页、Android 和 Windows 上使用。

**免费与付费**
调音器和每种乐器的前几节课免费。部分后续课程和额外工具属于可选升级。如果你已在使用这个应用，你现有的一切仍归你所有。

**隐私**
只有当你打开课程、调音器或钢琴检测时，Music Portal 才会请求麦克风权限，并会先说明原因。如果你拒绝，使用 MIDI 键盘或屏幕乐器的所有功能仍可正常使用。

有问题或想法？请使用应用内的“发送反馈”。
