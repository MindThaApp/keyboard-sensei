## Short description

あなたの演奏を聴いてくれるレッスンで、ピアノ・ギター・バイオリンを学べます。無料チューナーとアコースティックピアノのチェックも。

## Description

Music Portalは、あなたの演奏を聴いてくれる短くてやさしいレッスンで、ピアノ・ギター・バイオリンの上達を応援します。以前の名前はMidivoryで、アカウントと進捗はそのまま引き継がれます。

**聴いてくれるレッスン**
お持ちの楽器を演奏すると、Music Portalがマイクで聴きます。音とタイミングをチェックし、バイオリンでは各音がどれだけ音程に近いかも表示します。ギターではコードの正誤を、聞き取った内容のヒントとともに表示します。マイクが拾った音はすべてお使いのPC上で分析され、破棄されます。録音はされず、音声がアップロードされることもありません。

**ピアノ・ギター・バイオリン**
- ピアノ：USB MIDIキーボードまたは画面上のキーボードで演奏できます。アコースティックピアノでは、マイクモードで単旋律を採点します。Bluetooth MIDIキーボードは、Windowsでは後日対応予定です。
- ギター：五線譜とタブ譜、コードダイアグラム、画面上の指板。
- バイオリン：運指、ポジション、弓使いの記号、画面上の指板。
- 公開時点では、ギターとバイオリンのレッスンは最初の一歩から初級後半までです。今後さらに追加予定です。

**無料のチューナー**
クロマチックチューナーは、アカウントもインターネット接続も不要で使えます。ギターのプリセット（スタンダード、Drop D、DADGAD、オープンチューニングなど）、バイオリンのプリセット、ピアノモードから選べます。基準ピッチ（A4を415〜466Hz）を自分で設定し、カスタムチューニングも保存できます。

**ピアノチェック**
アコースティックピアノの調律が必要か気になりますか？ アプリが指定する音を弾くと、どの音が高い・低いか、どれくらいずれているか、ピアノ全体の音程が下がっていないかが分かります。分かりやすい判定が、ピアノ調律師を呼ぶかどうかの判断に役立ちます。測定のみで、調律の方法は教えません。ガイド付きの調律サポートは後日対応予定です。

**毎日少しずつ練習**
デイリーチャレンジ、クイズ、連続記録、経験値が、練習を続ける力になります。1つのアカウントで、ウェブ、Android、Windowsで使えます。

**無料と有料**
チューナーと、各楽器の最初のレッスンは無料です。後半のレッスンや追加ツールの一部は、任意のアップグレードに含まれます。すでにアプリをお使いの場合、現在お持ちのものはそのまま使えます。

**プライバシー**
Music Portalがマイクへのアクセスを求めるのは、レッスン、チューナー、ピアノチェックを開いたときだけで、先に理由を説明します。許可しない場合でも、MIDIキーボードや画面上の楽器を使う機能はすべて使えます。

ご質問やご意見は、アプリ内の「フィードバックを送信」からどうぞ。

## Features (one line each)

- ピアノ・ギター・バイオリンのレッスン
- マイクによる採点：音、タイミング、バイオリンの音程
- 聞き取った内容のヒント付きギターコードチェック
- 五線譜とタブ譜、コードダイアグラム、運指記号
- ギター・バイオリン・ピアノのプリセット付きクロマチックチューナー
- 調整できる基準ピッチとカスタムチューニング
- ピアノチェック：アコースティックピアノのどの音がずれているかを確認
- 画面上のピアノ、指板、バイオリンの指板
- デイリーチャレンジ、クイズ、連続記録、経験値
- USB MIDIキーボード対応
- マイクの音はデバイス上にとどまり、アップロードされません
